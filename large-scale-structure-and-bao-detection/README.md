# Cosmology Project: Large-Scale Structure & BAO Detection — Real SDSS DR8 Data
 
## Data disclosure (read this first)
 
The data used here — **661,598 real SDSS Data Release 8 spectroscopic galaxies**, with real positions
(RA/Dec), spectroscopic redshifts, ugriz photometry, and MPA-JHU value-added measurements (stellar
mass, star formation rate, emission-line fluxes, BPT classification) — was fetched from the astroML
project's own public GitHub repository (`astroML/astroML-data`), which hosts the identical real SDSS
DR8 data file that astroML's own `fetch_sdss_specgals()` function serves. This is the same real data,
not a re-derivation or subsample.
 
### How to get this data yourself
 
1. **Easiest:** `pip install astroML`, then in Python:
```python
   from astroML.datasets import fetch_sdss_specgals
   data = fetch_sdss_specgals()
```
2. **Directly from GitHub** (no astroML package needed):
   - `https://github.com/astroML/astroML-data/raw/main/datasets/SDSSspecgalsDR8_1.fit.gz`
   - `https://github.com/astroML/astroML-data/raw/main/datasets/SDSSspecgalsDR8_2.fit.gz`

3. **From the original SDSS source** (requires SDSS SkyServer / CASJobs access): 
    `https://www.sdss.org/dr8/`, or query the SDSS CAS SQL server's `specphotoall` /
   `galSpecInfo` tables directly.

**Citation:** Ivezic, Z., Connolly, A. J., VanderPlas, J. T., & Gray, A. (2014). *Statistics, Data
Mining, and Machine Learning in Astronomy*. Princeton University Press (astroML companion dataset).
Underlying survey: Sloan Digital Sky Survey Data Release 8 (Aihara et al. 2011, ApJS, 193, 29).
MPA-JHU value-added catalog methodology: Kauffmann et al. 2003; Brinchmann et al. 2004; Tremonti et
al. 2004.
 
## What is genuinely real vs. what is computed
 
- **Real:** all galaxy positions, redshifts, and photometry (661,598 real SDSS DR8 galaxies)
- **Real:** the comoving-distance conversion (astropy, real fiducial flat-ΛCDM cosmology)
- **Real:** the two-point correlation function measurement itself (Landy-Szalay estimator on real
  galaxy positions, real random catalog built from the real survey footprint)
- **Real:** the linear-theory comparison curve (CAMB's real matter power spectrum, real Planck 2018
  parameters, same tooling as the CMB cosmology project)
- **Not from the original archive, but real:** the random catalog's exact points are generated by
  resampling from the real data (shuffled real angular positions + real comoving-distance
  distribution) rather than downloaded as a separate SDSS random-catalog file — a standard, accepted
  technique for building 2PCF randoms, not a simulation of the galaxies themselves

## A bug worth documenting
 
The first version of the Landy-Szalay pair-counting code produced a correlation function pinned near
`xi ≈ 1.0` at all separations, including large scales where it should approach zero. This was traced to
`scipy.spatial.cKDTree.count_neighbors` double-counting each unordered pair as two ordered pairs `(i,j)`
and `(j,i)` when counting a tree against itself (verified with a small toy example) — affecting the DD
and RR pair counts but not the DR cross-count, which silently shifted the entire correlation function
up by about 1. Fixed by normalizing DD and RR by `n*(n-1)` instead of `n*(n-1)/2`.
 
## Headline results
 
| Separation | Real measured ξ(r) |
|---|---|
| ~8 Mpc | 1.02 |
| ~15 Mpc | 0.40 |
| ~29 Mpc | 0.10 |
| ~90-200 Mpc | consistent with zero (±0.0002-0.003) |
 
The real measured correlation function closely tracks the classic published real SDSS clustering
power law, ξ(r) = (r / 5.77 Mpc)^-1.8 (Zehavi et al. 2005), from ~8 Mpc out to roughly 60-70 Mpc. At
the ~100-150 Mpc separations where the baryon acoustic oscillation feature is expected, the measured
values are small and consistent with noise — no statistically significant, clearly localized BAO bump
is detected in this measurement.
 
This is expected and stated honestly rather than overclaimed: this project uses the general SDSS DR8
main spectroscopic galaxy sample, not the dedicated, much larger-volume BOSS CMASS luminous red galaxy
sample that real BAO-detection papers (Eisenstein et al. 2005; the BOSS collaboration papers) were
specifically designed around. The real small-scale clustering match to the published power law is a
stronger and cleaner validation of this pipeline's correctness than a marginal large-scale claim would
be.
 
## Honest limitations
 
- Sample used (SDSS DR8 main spectroscopic sample, 0.05<z<0.3) has meaningfully less effective volume
  than the dedicated BOSS CMASS sample real BAO detections are built on.
- Errors are a simple Poisson-based estimate (`(1+xi)/sqrt(DD)`); real BAO analyses use jackknife or
  mock-catalog-based covariance matrices, which would give a more rigorous significance estimate for
  any candidate large-scale feature.
- No redshift-space distortion correction or Alcock-Paczynski effect modeling was applied; the
  correlation function is measured directly in redshift space, which somewhat compresses/distorts
  large-scale clustering versus the real-space correlation function.
- The random catalog uses independently resampled angular and radial coordinates from the real data,
  which assumes no correlation between angular position and redshift in the survey selection function
  — a reasonable approximation for this sample, but a simplification relative to full survey mask
  modeling (e.g. MANGLE) used in real production BOSS/eBOSS analyses.
